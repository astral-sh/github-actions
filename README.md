# Astral GitHub Actions

Shared GitHub Actions for Astral projects.

- [Release smoke test](release-smoke-test/): test release artifacts in disposable containers.
- [PR security review](security-pr-review/): review pull requests with Codex Security.
- [Release signing scripts](setup-release-signing/README.md): macOS signing and
  notarization, wheel transforms, and native signature verification.
- [Windows signing](sign-windows/README.md): Azure Artifact Signing with publisher
  and timestamp verification.
